# Programming for Data Science – DSA & Analysis

Repository containing practical assignments, lab implementations, and algorithmic exercises for the Programming for Data Science course under the Online BSc/BS in Applied AI and Data Science program.

## 📚 Course Overview
This curriculum focuses on designing and implementing fundamental data structures, understanding algorithmic complexities, and applying efficient searching, sorting, and graph techniques to real-world data science workflows using Python.

## 🗓️ Syllabus & Course Roadmap

- **Programming Refresher** – Python fundamentals and core programming syntax.
- **Fundamentals of Algorithms** – Complexity, asymptotic notations, sorting, and searching algorithms.
- **Data Structures** – Arrays, Linked Lists, Stacks, Queues, Hashing, Heaps, and Sets.
- **Graph Algorithms** – Graph representations, traversals, and pathfinding.
- **Advanced Data Structures** – Union-Find, Priority Queues, Heaps, and Binary Search Trees.
- **Trees & Greedy Algorithms** – Balanced Search Trees (AVL/Red-Black concepts) and Greedy problem-solving.
- **String & Pattern Matching** – Algorithms for efficient string manipulation and searching.

## 🛠️ Lab & Practical Focus
- Hands-on implementation of core data structures using Python.
- Empirical verification and comparison of run-time performance and asymptotic behavior.
- Applying data structures to real-world data science scenarios and datasets.
